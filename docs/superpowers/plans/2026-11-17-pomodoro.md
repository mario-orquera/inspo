# Pomodoro Timer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a configurable pomodoro timer (panel button + dropdown) to the Inspo GNOME Shell extension.

**Architecture:** A pure state machine (`pomodoro.js`) is driven by a 1 s GLib tick in `extension.js` and rendered by a `PanelMenu.Button` subclass (`pomodoroUi.js`). Config lives in GSettings; the dropdown writes it back.

**Tech Stack:** GJS (ES modules), GNOME Shell 49 extension API, GSettings, Nix.

**Spec:** `docs/superpowers/specs/2026-11-17-pomodoro-design.md`

## Global Constraints

- Shell version 49 only; same extension uuid `inspo@mario`; no new extension.
- Defaults: focus 25, short break 5, long break 15 minutes; long break after 4 focus sessions. All minimums are 1.
- Phases never auto-start; a phase end moves to the next phase paused and notifies via `Main.notify()`.
- Running timer is not persisted; settings and `task` are.
- A length change applies from the next phase (never alters a running countdown); while idle it applies immediately.
- Time comes from an injected clock (end timestamp), never from counting ticks.
- `pomodoro.js` has no `gi://` or `resource://` imports.
- Pomodoro button sits on the right of the panel; the message label is untouched.
- `disable()` leaves no timer source, signal connection or actor behind.
- Out of scope: sound, auto-start, stats, prefs window.
- Tests run with `nix-shell -p gjs --run "gjs -m tests/<file>"` (gjs is not installed globally); tests print `ok` and exit 0 on pass.

## Review Focus

- Large clock jump (suspend/resume) across a phase boundary: ends exactly one phase, next phase starts with its full duration, no cascade.
- Pause then resume later: remaining time is unchanged by the pause duration.
- Config value of 0 or negative (e.g. edited via gsettings/dconf): clamped to at least 1 minute, never an instant phase end.
- `start()` on a running timer, `pause()` when not running, `skip()`/`pause()` when idle: harmless no-ops.
- Disabling the extension mid-run, and a very long task string: no leaked tick, and the dropdown width stays bounded.

## File Structure

- `pomodoro.js` (create): state machine.
- `tests/pomodoro.test.js` (create): its tests.
- `schemas/org.gnome.shell.extensions.inspo.gschema.xml` (modify): new keys.
- `pomodoroUi.js` (create): panel button + dropdown.
- `extension.js` (modify): create/destroy button, tick, notifications, settings wiring.
- `stylesheet.css` (modify): phase classes and dropdown layout.
- `default.nix` (modify): install new files.

### Task 1: Pomodoro state machine

**Files:**
- Create: `pomodoro.js`
- Test: `tests/pomodoro.test.js`

**Interfaces:**
- Produces:
  - `export const Phase = {IDLE: 'idle', FOCUS: 'focus', SHORT: 'short', LONG: 'long'}`
  - `export class Pomodoro`
    - `constructor(config: {focus: number, short: number, long: number, every: number}, now: () => number)`: minutes and a millisecond clock; values below 1 are clamped to 1.
    - `get phase(): string`
    - `get running(): boolean`
    - `get sessions(): number`: focus sessions completed since the last long break.
    - `remainingMs(): number`: for idle, the full focus duration.
    - `dots(): {filled: number, total: number}`: `total` is `every`; `filled` is `sessions % every`, but `every` while in the long break.
    - `start(): void`: idle becomes running focus; paused resumes; running is a no-op.
    - `pause(): void`: no-op unless running.
    - `skip(): void`: moves to the next phase paused; no-op when idle. Skipping focus does not count a session.
    - `reset(): void`: idle, sessions 0.
    - `tick(): string | null`: if running and time is up, moves to the next phase paused and returns the phase that ended; otherwise `null`.
    - `setConfig(config): void`: stored; read at phase entry, so a running or paused phase keeps its duration.
  - Next phase rule: focus ends → `sessions++`, then long if `sessions % every === 0`, else short; any break ends → focus (after a long break `sessions` resets to 0).

- [ ] **Step 1: Write failing tests in `tests/pomodoro.test.js`** with the same `assertEquals` helper as `tests/messages.test.js` and a fake clock `let t = 0; const now = () => t;`. Config `{focus: 25, short: 5, long: 15, every: 4}`. Cover:
  - fresh machine: phase `idle`, `running` false, `remainingMs()` 1500000.
  - `start()` then `t = 60000`: phase `focus`, running, `remainingMs()` 1440000.
  - `pause()` at 60000, `t += 600000`, `start()`: `remainingMs()` still 1440000 (Review Focus: pause/resume).
  - `t` jumps 10 hours past the end: `tick()` returns `'focus'`, phase `short`, `running` false, `remainingMs()` 300000, and a second `tick()` returns `null` (no cascade).
  - four full focus sessions: phases go focus, short, focus, short, focus, short, focus, long; `sessions` is 4 and `dots()` is `{filled: 4, total: 4}` during long; after the long break ends, phase `focus`, `sessions` 0.
  - `dots()` after two completed sessions during a break is `{filled: 2, total: 4}`.
  - `skip()` from focus goes to a paused `short` without incrementing `sessions`; `skip()` from a break goes to a paused `focus`; `skip()` on idle changes nothing.
  - `reset()` from mid-run: phase `idle`, `sessions` 0, not running.
  - `start()` twice does not restart the countdown; `pause()` on idle/paused does nothing (Review Focus: no-ops).
  - `setConfig({focus: 50, ...})` while a focus phase runs leaves `remainingMs()` unchanged; the next focus phase lasts 50 min; while idle, `remainingMs()` is 3000000 immediately.
  - config with `focus: 0` and `short: -3` clamps to 1 minute (60000 ms) (Review Focus: clamping).
  - ends with `print('ok');`.

- [ ] **Step 2: Run** `nix-shell -p gjs --run "gjs -m tests/pomodoro.test.js"`. Expected: FAIL (module missing).

- [ ] **Step 3: Implement `pomodoro.js`** per the Interfaces block. Store `_endAt` (ms) while running and `_remaining` (ms) while paused/idle; derive remaining from the injected clock.

- [ ] **Step 4: Run the test command again.** Expected: exits 0, prints `ok`.

### Task 3: Panel button and dropdown

**Files:**
- Create: `pomodoroUi.js`
- Modify: `stylesheet.css`

**Interfaces:**
- Consumes: `Phase`, `Pomodoro` API from Task 1 (`phase`, `running`, `remainingMs()`, `dots()`, `sessions`); settings keys from Task 2.
- Produces: `export class PomodoroButton extends PanelMenu.Button`
  - `constructor(machine: Pomodoro, settings: Gio.Settings, callbacks: {onAction: () => void})`: `onAction` is called after any start/pause/skip/reset press so the extension can re-arm or stop the tick.
  - `refresh(): void`: re-renders panel text/style class and the dropdown from the machine.
  - `destroy()` (inherited): must disconnect its own settings handlers.

- [ ] **Step 1: Build the panel part.** Icon plus label showing `MM:SS`; idle shows only the icon (label hidden). Style classes `inspo-pomo-focus`, `inspo-pomo-break`, `inspo-pomo-paused` on the button, set from the machine state in `refresh()`.

- [ ] **Step 2: Build the dropdown.**
  - Phase title and large readout.
  - Button row: start/pause (toggles by `machine.running`), skip, reset, each calling the machine, then `refresh()` and `onAction()`.
  - Dot row from `dots()`.
  - Task entry bound to the `task` key; save on activate and on `key-focus-out`; width capped with `set_style('max-width: 280px;')` (Review Focus: long task).
  - `PopupSubMenuMenuItem` "Settings" with a stepper row (label, `−`, value, `+`) for each of `focus-minutes`, `short-break-minutes`, `long-break-minutes`, `sessions-before-long`, `rotation-minutes`. Steppers clamp to the key's schema range, write via `settings.set_int`, and update their displayed value from `changed::<key>`.

- [ ] **Step 3: Add CSS** to `stylesheet.css` for the three phase classes (accent for focus, green for break, `opacity` for paused), the large readout, and the dot row.

- [ ] **Step 4: Verify syntax.** Run `nix-shell -p gjs --run "gjs -m -c 'import(\"./pomodoroUi.js\")' 2>&1 | head"` is not meaningful outside Shell; instead run `nix-shell -p nodejs --run "node --check pomodoroUi.js"`. Expected: no output. Visual verification happens in Task 4.

- [ ] **Step 5: Commit**


### Task 4: Wire into the extension, package, verify

**Files:**
- Modify: `extension.js`, `default.nix`

**Interfaces:**
- Consumes: `Pomodoro` (Task 1), `PomodoroButton` (Task 3), the keys from Task 2.

- [ ] **Step 1: In `extension.js` `enable()`:**
  - Create `this._pomodoro = new Pomodoro(config, () => GLib.get_monotonic_time() / 1000)`, with `config` read from settings by a small `_pomoConfig()` helper.
  - Create `this._pomoButton = new PomodoroButton(this._pomodoro, this._settings, {onAction: () => this._syncPomoTick()})`.
  - Add it with `Main.panel.addToStatusArea('inspo-pomodoro', this._pomoButton, 0, 'right')`.
  - Connect `changed::` for the four length keys to `this._pomodoro.setConfig(this._pomoConfig())`.

- [ ] **Step 2: Tick.** `_syncPomoTick()` starts a 1 s `GLib.timeout_add_seconds` source when `this._pomodoro.running` and none exists, and removes it when not running. The tick callback calls `this._pomodoro.tick()`; if it returns a phase, call `Main.notify()` with a title like "Focus done" and a body like "Take a 5 minute break" (use the configured minutes; for a break ending: "Break over — ready to focus?"); then `this._pomoButton.refresh()` and `_syncPomoTick()`. Return `GLib.SOURCE_CONTINUE` while running.

- [ ] **Step 3: `disable()`** removes the tick source, disconnects the four settings handlers, destroys `_pomoButton`, and nulls `_pomodoro` (Review Focus: no leak on disable).

- [ ] **Step 4: `default.nix`:** add `pomodoro.js pomodoroUi.js` to the `cp` line.

- [ ] **Step 5: Run all tests.** Run `for f in tests/*.test.js; do nix-shell -p gjs --run "gjs -m $f" || echo FAIL $f; done`. Expected: three `ok`, no `FAIL`.

- [ ] **Step 6: Manual verification in a nested shell** (`dbus-run-session gnome-shell --nested --wayland`, extension symlinked as in the Inspo plan). Check, and report what was observed for each:
  - idle shows icon only; start shows `25:00` counting down in the focus color.
  - pause dims it; resume continues from the same time.
  - set focus to 1 minute in Settings, start: a notification appears at 0:00 and the panel moves to a paused short break.
  - skip and reset behave as in the spec; the dots fill after each focus session.
  - a very long task string does not widen the dropdown.
  - disable then enable the extension: no errors in `journalctl --user -b | grep -i inspo`, and one pomodoro button only.

- [ ] **Step 7: Commit**

```bash
git add extension.js default.nix
git commit -m "feat: wire pomodoro into the extension"
```
