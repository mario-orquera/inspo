# Inspo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A GNOME Shell 49 extension that shows one random inspirational line from a text file beside the top-panel clock, rotating on a timer and on click.

**Architecture:** Pure logic (`messages.js`) is separated from Shell wiring. `store.js` loads and watches the file. `extension.js` injects an `St.Label` into the date menu button and drives a rotation timer. Packaged as a Nix derivation at the end.

**Tech Stack:** GJS (ESModules), GNOME Shell 49 extension API, GSettings, Nix (`stdenv.mkDerivation`).

**Spec:** `docs/superpowers/specs/2026-10-02-inspo-design.md`

## Global Constraints

- `metadata.json`: `uuid` = `inspo@mario`, `shell-version` = `["49"]`.
- Messages file: `~/.config/inspo/messages.txt`, one per line; blank lines and lines starting with `#` ignored.
- GSettings schema id `org.gnome.shell.extensions.inspo`, key `rotation-minutes` (int, default 10).
- Never show the same message twice in a row unless only one message exists.
- `disable()` must remove the label, stop the timer, and cancel the file monitor.
- No popups, notifications, prefs GUI, or popover (out of scope).
- Tests for pure logic run under plain `gjs -m`.

## Review Focus

- Messages file with CRLF line endings: lines must not keep a trailing `\r`.
- Messages with leading/trailing whitespace: trimmed.
- File deleted or replaced while running (editors write via rename): monitor must survive and reload; no crash.
- `rotation-minutes` set to 0 or negative: clamp to at least 1 minute, never a busy loop.
- Enable/disable/enable cycles (lock screen toggles extensions): no duplicate labels or leaked timers.

**Interfaces:**

It also starts a `Gio.FileMonitor` that reloads and calls `onChange` on change.

### Task 4: Extension wiring

**Files:**
- Create: `extension.js`, `stylesheet.css`

**Interfaces:**
- Consumes: `MessageStore`, `pickNext`, GSettings key `rotation-minutes`.
- Produces: `export default class InspoExtension extends Extension` with `enable()` and `disable()`.

- [ ] **Step 1: Implement `enable()`.**
  - Create the settings via `this.getSettings()`.
  - Create the store at `GLib.get_user_config_dir()/inspo/messages.txt`.
  - Create an `St.Label` (style class `inspo-label`, `reactive: true`, `track_hover: true`, max width ~400 px, `clutter_text.ellipsize = Pango.EllipsizeMode.END`).
  - Insert it into `Main.panel.statusArea.dateMenu._clockDisplay.get_parent()` immediately before the clock display.
  - Show an initial message.
- [ ] **Step 2: Rotation.** `_rotate()` sets the label text from `pickNext(store.messages, current)`. When the result is `null`, hide the label. A `GLib.timeout_add_seconds` timer with interval `max(1, rotation-minutes) * 60` calls it. The timer re-arms when the setting changes (`changed::rotation-minutes`) and on a manual skip. The store's `onChange` calls `_rotate()`.
- [ ] **Step 3: Click to skip.** Handle `button-press-event` on the label by rotating, resetting the timer, and returning `Clutter.EVENT_STOP` so the calendar menu does not open.
- [ ] **Step 4: Tooltip.** Full text is shown on hover via the label's `hover` notify (a simple `St.Label` tooltip or setting `accessible_name`; keep it minimal).
- [ ] **Step 5: `disable()`** removes the source id, destroys the store, disconnects settings signals, destroys the label, and nulls every field.
- [ ] **Step 6: Create `stylesheet.css`** with `.inspo-label` (padding-right and a slightly reduced opacity so the clock stays dominant).
- [ ] **Step 7: Commit** (`feat: wire extension into date menu`).
